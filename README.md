# Android Notes App

A small Android project built with Kotlin to explore working with data on mobile devices.

## About

This project was developed over a few days as a learning experiment. My main goal was to gain practical experience working with data on an Android device, rather than building a fully featured application.

The app allows users to write notes, select photos from their device's gallery, and save their content. While working on this project, I explored how Android applications handle user input, access images from the device, and store data locally.

## Features

- Write and create notes
- Select photos from the device gallery
- Attach images to notes
- Save notes for later access

## Technologies

- Kotlin
- Android
- Local data storage
- Android photo picker / gallery integration

## Project Goals

The main purpose of this project was to learn more about Android data handling, local storage, and accessing user-selected media. It was a short practical experiment that helped me explore Android development beyond the user interface.

## Project Status

This project was created as a short learning experiment and is not intended to be a fully featured application.
